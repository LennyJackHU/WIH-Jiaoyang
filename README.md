# WIH-Jiaoyang

这是一个用于 **ESP32 开发板协作开发** 的仓库，供团队成员共享代码、实验记录和硬件开发相关资料。

## 仓库目标

- 统一管理 ESP32 项目代码
- 记录开发板配置、接线和调试信息
- 方便团队成员协作开发、提交和审查变更

## 开发环境

项目可根据具体需求使用以下任一开发方式：

- Arduino IDE
- PlatformIO
- ESP-IDF

提交代码时，请同时说明使用的开发框架、ESP32 开发板型号，以及必要的依赖或配置。

## 协作约定

1. 从 `main` 分支创建功能分支。
2. 提交信息应简明描述本次变更。
3. 提交前请在实际 ESP32 开发板上验证相关功能。
4. 涉及引脚、供电或接线变化时，请在提交说明或文档中注明。
5. 不要提交 Wi-Fi 密码、API 密钥或其他敏感信息。

## 项目结构

随着项目内容增加，可以按使用的开发框架补充以下目录：

```text
.
├── README.md
├── src/          # 应用源码
├── include/      # 头文件
├── lib/          # 本地库
├── docs/         # 接线、配置和实验记录
└── test/         # 测试代码
```

## 后续开发

请在开始具体功能开发前补充以下信息：

- ESP32 开发板的具体型号
- 使用的开发框架和版本
- 目标功能及验收方式
- 所需传感器、执行器或其他外设
