# 接线说明 — ESP32-S3-DevKitC-1 × Waveshare 1.54" e-Paper（V2/V2.1 驱动板）

屏幕规格：200×200 黑白，SPI 接口，驱动板 8PIN 排座（2.54mm）。V2.1 驱动板自带电平转换，3.3V 直连即可。屏幕背面有 V2 标签；若实际是 V1 老板（IL0373），需把 `src/display.h` 中的 `GxEPD2_154_D67` 换成 `GxEPD2_154`。

所有板固定使用 **N8R8：8 MB QIO Flash + 8 MB OPI PSRAM**。唯一固件环境及默认环境为 `esp32-s3-devkitc-1-n8r8`，直接运行 `pio run` / `pio run -t upload`，无需 `-e`。GPIO35–37 专用于存储器，不能接外设；当前 UART/屏幕/编码器引脚不占用这些存储器引脚。

DevKitC PCB 版本仍要区分：RGB LED 在 **v1.1 是 GPIO38、v1.0 是 GPIO48**，可通过 `PIN_RGB_LED` 覆盖；这与固定 N8R8 存储配置是两件事。

## Pogo 邻接 UART（候选引脚，待实板复核）

| 接口 | 控制器 | TX | RX | 连接关系 |
|---|---|---:|---:|---|
| 左邻 L | UART1 | GPIO17 | GPIO18 | 接左侧模块的 R 口 |
| 右邻 R | UART2 | GPIO15 | GPIO16 | 接右侧模块的 L 口 |

两端均为 115200、8N1、3.3V UART；TX 对 RX、RX 对 TX，并必须共地。固件为每口配置 4096 B RX/TX 缓冲并记录 UART 错误计数，BUSY 等待期间继续服务协议。地触点应先接后断；不跨模块连接电池正极、3.3V 或 5V。烧录前还要把 `src/config.h` 的 kit、recorder 和最多三个 member ID 配成实际设备值，占位 ID 会拒绝通信。

**直连 GPIO 不等于可安全带电插拔。** 原型每个 L/R 邻接口建议使用一片 SN74LVC2G125：两个通道分别隔离本机 TX 和远端 RX，`/OE` 默认上拉禁用，信号串联约 220Ω，缓冲器输入及 MCU RX 用 10k～47kΩ 上拉保持空闲高，触点旁增加低电感 TVS 回流。地触点必须以机械 first-mate/last-break 保证先接后断，镜像和 TX/RX 逐点导通验证。阻值只是调试起点，不是厂家指定值；`Ioff` 只保证器件 VCC=0V 时的高阻/漏电特性，不保证所有电源斜坡和系统级 ESD。

必须实测单侧掉电倒灌、慢/快电源斜坡、`/OE` 波形、单线断开、接触抖动和触点 ESD。通过这些之前只能说“协议支持重连”，不能说“电气上支持安全热插拔”。官方器件依据包括 ESP32-S3/DevKitC-1 数据手册、ESP32 硬件设计指南和 TI SN74LVC2G125 数据手册；社区 UART 倒灌案例仅作风险旁证。

## 交互逻辑（V2.0 约定）

- **Picker**：编码器双向无终点选词，相邻词不重复。A 第一次确认、第二次向唯一直接邻居主动 offer；无邻居或有两个邻居时只提示。B 刷新、取消确认或取消本机 pending。
- **Sentence / Navigate**：任何收词都进入句子页，句子最多 12 个有序词。无连接时编码器循环高亮，A 弹出 `delete? y/n`，再 A 删除、B 取消；Navigate 的 B 清句回 Picker。删到空句仍留 Sentence。
- **Sentence / InsertSide**：唯一有效邻居下 A 进入并显示 remote candidate，B 切换 `L BEFORE` / `R AFTER`，A 发 WORD_PULL 按 cursor 前/后位置拉取；空句也可拉取。
- **物理左右与句内位置**：定位 pull 只由 `pos` 决定，UART L/R 不再决定插入位置。只有无 `pos` 的主动 offer 按接收入边默认 Left 到句首、Right 到句尾；换向重连不搬动已插入的词。
- **完成与重试**：接收方即句子块；发送方收到应用层 ACCEPT 后才重新随机。OFFER/PULL/ACCEPT 丢失或运行中断线时保留 req 重试且不重复插入；已收句子不因拔线消失。B 取消本机 pending 不会远程撤销对端已入句内容。
- **持久化边界**：WIH4 保存句子顺序、cursor、来源和 receipts；编辑模式与 offer/pull pending 不保证跨断电恢复，断线重试不等于断电续传。
- **刷新率控制**：滚动使用全屏范围的快速局刷，确认/取消只刷新中央 200×62 区域；句子与通信状态变化使用整屏区域。每 20 次局部刷新自动全刷一次；单机无操作约 5 秒深睡，联机或等待传词时仅屏幕休眠、UART 保持工作。

完整模式切换、按键上下文、双机例子和协议时序见 [句子编辑器说明](sentence-editor.md)。

## 按钮（开机自动识别每个引脚的触发极性）

不同批次的按钮模块电气特性可能不同（有的空闲为高、有的空闲为低）。固件开机采样 60ms 自动判定：空闲读高 → 低电平触发并启用上拉；空闲读低 → 高电平触发并启用下拉。**开机瞬间请勿按住按钮**（自锁按钮请先确保处于弹起态）。低有效按钮需要确定的上拉，高有效按钮需要确定的外部下拉；不支持无外部上下拉的悬空输入。深睡唤醒使用 RTC 中保存的极性，不重新采样，唤醒按下的那一次只负责唤醒，释放后才恢复业务输入。

| 按钮 | DevKitC-1 | GPIO | 功能 |
|---|---|---|---|
| A | 7 | GPIO7 | Picker 确认/再次按下 offer；Sentence 删除确认或进入/发起定位 pull；单机休眠唤醒源（电平随极性自动配置） |
| B | 8 | GPIO8 | Picker 刷新/取消；DeleteConfirm 取消删除；InsertSide 切换 BEFORE/AFTER；Navigate 清句；pending 时优先取消本机请求（不作唤醒源） |

只有屏幕+单按钮的板子：按钮接 GPIO7 即可，GPIO8 留空。

注意：单机休眠后**按 A 唤醒**（这一下只唤醒、不触发动作），之后按键/转动编码器正常工作；编码器不作唤醒源（其电平在机械档位间不定，会导致睡眠唤醒抖动）。

## 使用注意（来自微雪手册）

- 局部刷新连续多次后需全刷一次（固件已每 20 次局部刷新自动全刷）；多位置局刷后若字体变浅，改为每 5 次全刷并复测。
- 无操作约 5 秒且画面更新完成后，单机让屏幕 hibernate 并让 MCU 深睡；有 UP 邻接或待确认传词时只让屏幕 hibernate，MCU 继续握手和重试。画面保持，实际休眠电流以实测为准。
- 按按钮 A 唤醒，唤醒后不重绘，直接恢复滚动；下一次内容变化必须先全刷。
- FPC 排线脆弱，调试时先固定排线；长期存放前先清屏。完整约束与验收见 `docs/display-design-requirements.md`。
